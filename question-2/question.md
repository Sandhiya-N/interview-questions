2. String Challenge – Matching Characters

**Problem Statement:

Write a function `StringChallenge(str)` that finds the maximum number of unique characters between any pair of matching characters in a given string.

**Rules:**
- Find matching character pairs in the string.
- Count the unique characters between each matching pair.
- Return the maximum count.
- If no matching pairs exist, return `0`.

**Examples:**

**Example 1:**
- Input: `"ahyakjh"`
- Output: `4`

**Example 2:**
- Input: `"gheccgkaem"`
- Output: `5`

**Example 3:**
- Input: `"mmnerme"`
- Output: `3`

**Function Name:** `StringChallenge`

**Language:** Python 3
